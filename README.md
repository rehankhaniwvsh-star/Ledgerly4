# Invoiceify — Branded Invoice Generator & Management Studio

**Invoiceify** is a high-performance, elegant, full-stack invoice generation and client management platform tailored for freelancers, agencies, and small businesses.

---

## 🌟 Key Features

- 📄 **Interactive Invoice Studio**: Real-time editor with live printable document preview, customizable currencies (₹, $, €, £), line items, tax rates, and discount calculations.
- 🎨 **CMS & Brand Customization**: Instant live updates for business name, contact info, logo letter mark, primary brand accent colors, and custom typography.
- 📊 **Invoice Management Dashboard**: Track invoice states (`Draft`, `Sent`, `Overdue`, `Paid`), search, duplicate, edit, or delete invoices.
- 📥 **Direct PDF Download & Printing**: Download crisp client-ready PDF invoices directly or trigger browser print styling.
- 📧 **Client Sharing & Email Modal**: Pre-formatted client email notifications and shareable invoice link generation.
- 💾 **Local Persistence**: Works offline and persists invoice records and brand settings safely in local storage.

---

## 🚀 Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Icons**: Lucide React
- **PDF Export**: html2pdf.js / Custom Print Layouts
- **Backend / Dev Server**: Node.js, Express, Vite

---

## 🛠️ Local Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

4. **Start Production Server**:
   ```bash
   npm run start
   ```
